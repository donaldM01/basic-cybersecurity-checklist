# Cybersecurity Incident Response Toolkit

## Overview
This repository provides a standardized toolkit for Junior Cybersecurity Analysts and Incident Responders. It includes structured incident reporting templates and triage checklists designed to streamline incident handling, ensure compliance, and maintain clear records during security events.

## Project Structure
- `templates/incident-reporting-template.md`: A standardized form for reporting security incidents.
- `checklists/incident-triage-checklist.md`: Step-by-step guidance for initial triage and containment.
